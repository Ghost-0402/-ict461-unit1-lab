# ICT461 — Unit 1 Lab: Course Registration Interface

A one-page course registration interface built for ICT461, using semantic HTML, responsive CSS, and a JavaScript interaction.

## Features

- Semantic HTML structure (`header`, `main`, `footer`, with `aria-labelledby` linking sections to their headings)
- Responsive layout that adapts to smaller screens
- Live "Registration Summary" panel that updates instantly via JavaScript as the form is filled in — no page reload
- Form validation with accessible error messages (`aria-invalid`, `role="alert"`)
- Keyboard-friendly, native HTML controls throughout

## Accessibility

Tested with Lighthouse. An initial audit scored 19/20, flagging a color contrast issue on hint/footer text. This was fixed by darkening the muted text color, bringing the score to a perfect 20/20.
